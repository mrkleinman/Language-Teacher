# Brief: find the CORE spoken-Cantonese words missing from the list

The Cantonese list (2,500 curriculum words) was adapted from a Mandarin-based HSK deck plus 500 Hong Kong local-context words. The module writers found that some of the MOST BASIC Cantonese words are not in it at all: 想 (want to), 會 (will / can), 未 (not yet), 呢度 and 嗰度 (here / there), 但係 (but), 話 (say / tell), 行 (walk), 幾時 (when), 邊啲, 咋, 嘅 is there, 哋 as in 你哋 / 佢哋 (you all / they) ... They are missing because the Mandarin list had other words in their place.
Your job: list the core everyday words a Hong Kong speaker uses constantly that are NOT in the list, so they can be added at the very start of the curriculum (these are the true 20% that carry 80% of speech).
`input/deck-headwords.txt` = every headword already in the list (do NOT propose these; a different SENSE of a listed headword also counts as missing only if it is a core sense, say so in `why_missing`).
Think systematically through: pronouns and plurals (你哋 佢哋 自己 人哋), demonstratives and place words (呢度 嗰度 呢個 嗰個 呢啲 嗰啲 邊啲 上面 下面 入面 出面 前面 後面 隔離 附近), question words (幾時 點解 邊 乜 咩 點), modals and want / can / should (想 會 可以 要 應該 肯 敢 識), negation and aspect (未 冇 唔 咗 緊 過 吓 開), copula and existence (係 喺 有 冇 響), conjunctions and discourse (但係 不過 所以 因為 如果 同埋 仲 又 先 就 都 才 啱啱 已經 一定 可能), degree and frequency (好 好似 非常 最 更 比較 成日 好多 一啲 少少 啲), time (而家 琴日 聽日 尋日 今晚 朝早 晏晝 夜晚 星期 禮拜 點鐘 號 月 年), numbers and measure words (一 二 兩 三 … 十 百 千 萬 個 隻 張 條 件 本 杯 碗 位 次 啲), core verbs (話 講 睇 聽 食 飲 去 嚟 返 行 企 坐 瞓 買 賣 畀 搵 揾 拎 俾 開 閂 做 玩 學 教 記得 唔記得 知 識 明 鍾意 喜歡 驚 等 試 幫 借), core adjectives, common nouns (人 嘢 時間 地方 錢 屋企 朋友 老師 學校 公司), greetings and politeness, sentence-final particles (啦 喇 喎 㗎 啫 咩 呀 嘅 囉 嘛 咋 啩).
Write only words you are SURE are standard, everyday Hong Kong Cantonese (traditional characters). Check each against the headword file with a script and drop the ones already in the list.
Output: `drafts/core/C01-candidates.csv` (UTF-8 with BOM), header exactly
`word,jyutping,meaning,pos,use_class,tier_hint,group,subgroup,frame,english_slot,english_plural,classifier,confidence,note`
with the same field rules as `BRIEF_LOCAL.md` and `BRIEF_TAG.md` (read both; subgroups: reuse names from `input/existing-cells.txt` where they fit; X_ groups for function words; use_class A or B only; tier_hint T1 for the first 200 words of a learner's life, T2 for the next 600). Add one more column at the end: `why_missing` (e.g. "deck has 諗 but not 想"). Aim for 100-150 candidates, the most important first. Run a script check (no duplicates, none in the headword file, Jyutping syntax valid, allowed values). Do not edit any other file and do not commit. Report: rows, and the 15 most important words you added.
