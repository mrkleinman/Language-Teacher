## Needs your decision: the new words change some generator and QC results

No code changed. But the app's existing rules read the dictionary, so adding 151 words changes some of their results. Four existing regression tests now fail because of this, and I have **not** changed those tests: they show real behaviour changes.

| Test | What now happens | Cause |
|---|---|---|
| tests45 P2 (recorded live Thai Daily run, replayed) | The line ผมหมายถึง การไปเที่ยวครับ is now rejected as "untaught vocabulary: การ", and the run no longer replays. | Item 1 below. |
| tests39 C1 (Gen2 simulator recordings) | All 7 Thai recordings no longer replay identically. Japanese and Mandarin still do. | Same cause. |
| tests40 T2 (target-word detection) | น้ำแข็ง ("ice") now counts as a use of the target น้ำ ("water"). | แข็ง is now a dictionary word. The existing compound rule treats a target followed by a known word as that target (here น้ำ + แข็ง). |
| tests42 P3 (romanisation grouping) | อ่านหนังสือพิมพ์ now reads àan nǎng-sǔue phim instead of àan nǎng-sǔue-phim. | พิมพ์ is now a dictionary word, so the splitter separates it. |

Fixing these would need a code change, which this task does not allow. Two options:

- **Accept them.** This is the app's designed rule: a dictionary word must be taught before it may appear. The cost is more rewrites in Daily until you reach these words.
- **Approve a small, separate code change**, for example:
  - keep "always allowed" grammar words such as การ and ความ allowed until they are introduced;
  - keep น้ำแข็ง from counting as น้ำ.

## Things you should know

1. **Twelve words lose their "always allowed" status until you are taught them.**
   - Which words:

     | Slot | Word | Slot | Word | Slot | Word |
     |---|---|---|---|---|---|
     | 509 | อย่าง | 511 | ทั้ง | 521 | การ |
     | 522 | ความ | 538 | สิ่ง | 539 | ปัญหา |
     | 541 | คำ | 568 | สวน | 652 | เท่า |
     | 662 | ผล | 693 | เสิร์ฟ | 774 | รสชาติ |

   - Why: the app already has a rule that a dictionary word may appear in a generated sentence only after the learner has been introduced to it. The "always allowed" list applies only to words that are not in the dictionary.
   - Effect: these 12 words were on that list. Now that they are curriculum words, the existing rule locks them until they are introduced.
   - No code changed for this. It is the existing rule applied to the new data.
   - Most of them sit early in 8th Kyu, which you are studying now.
2. **Four requested words cannot be Daily targets.** จะ (501), ของ (504), และ (506) and เธอ (518) are on the app's existing "not generatable" list of function words. They count toward the belt but are never picked as Daily targets. Nothing was changed.
3. **Five reused records keep an existing special label.** I left these labels unchanged because they are existing lexical data:
   - "recognition only": และ (506), รถยนต์ (573), เพียง (618), บัตรคิว (709);
   - "context only": ปวดหัว (792).
